## Stack du site

Next.js (export statique), React, Tailwind CSS, déployé sur GitHub Pages via GitHub Actions.

```bash
# Installation
pnpm install

# Développement
pnpm dev

# Build statique (dossier out/)
GITHUB_PAGES=true pnpm build
```

Sous Windows PowerShell :

```powershell
$env:GITHUB_PAGES="true"; pnpm build
```
